## なぜChatGPTの回答は長くなるのか

ChatGPTには「ユーザーの意図が不明確なら、幅広くカバーして答える」という傾向があります。

つまり、こちらが曖昧な質問をすると：
- 前提の説明から始める
- 複数の解釈を網羅する
- 念のため注意事項も追加する

結果、3行で済む回答が30行になります。

**解決策はシンプル**：こちらが「何が欲しいか」を明確にすれば、ChatGPTはそれに合わせて答えてくれます。

## テクニック1：出力形式を指定する

### 追加する1行

```
箇条書き3つで答えてください。
```

### Before（指定なし）

**質問**: Pythonの仮想環境を使うメリットを教えて

**回答**: Pythonの仮想環境（venv）は、プロジェクトごとに独立したPython環境を作成するための機能です。仮想環境を使うメリットは多岐にわたりますが、まず第一に…（以下800文字）

### After（形式指定あり）

**質問**: Pythonの仮想環境を使うメリットを教えて。箇条書き3つで答えてください。

**回答**:
- プロジェクトごとにパッケージのバージョンを分離できる
- グローバル環境を汚さないので、他のプロジェクトに影響しない
- requirements.txtで依存関係を共有しやすくなる

回答量が1/10になりました。欲しい情報はちゃんと入っています。

Python仮想環境について詳しく知りたい方は[Python仮想環境の基本](/posts/python-venv-beginner/)（ググワカ）も参考にしてください。

## テクニック2：文字数・行数を制限する

### 追加する1行

```
100文字以内で答えてください。
```

### 使い分け

| 制限の仕方 | 使いどころ |
|------------|-----------|
| 〇〇文字以内 | SNS投稿の下書き、メールの件名 |
| 〇行で | 要約、概要説明 |
| 一言で | 定義の確認、Yes/No判断 |

### 実例

**質問**: APIとは何か、一言で説明してください。

**回答**: 異なるソフトウェア同士がデータをやり取りするための窓口です。

## テクニック3：回答に含めないものを指示する

### 追加する1行

```
前置きと注意書きは省略してください。
```

### Before

**質問**: JavaScriptのmapメソッドの使い方を教えて

**回答**: JavaScriptのmapメソッドは、配列の各要素に対して関数を適用し、その結果から新しい配列を生成するための非常に便利なメソッドです。ES6で導入され…（前置き200文字）…なお、mapメソッドを使用する際は元の配列が変更されないことに注意してください。また…（注意書き200文字）

### After

**質問**: JavaScriptのmapメソッドの使い方を教えて。前置きと注意書きは省略してください。

**回答**:
```javascript
const numbers = [1, 2, 3];
const doubled = numbers.map(n => n * 2);
// [2, 4, 6]
```

mapは配列の各要素に関数を適用して新しい配列を返します。

体感で回答量が半分以下になります。すでに前提知識がある人にとって、前置きの説明は不要ですから。

## テクニック4：ロール（役割）を設定する

### 追加する1行

```
あなたはシニアエンジニアです。初心者向けの説明は不要です。
```

### なぜ効くのか

ChatGPTはデフォルトで「相手が初心者かもしれない」と想定して答えます。ロールを設定すると、こちらのレベルに合わせた回答になります。

### レベル別の設定例

| 自分のレベル | ロール設定 |
|-------------|-----------|
| 完全初心者 | 「小学生にも分かるように説明してください」 |
| 学習中 | 「プログラミング学習1年目の人に教えるように」 |
| 実務者 | 「シニアエンジニア同士の会話のように答えてください」 |
| 専門家 | 「コード例だけ出してください。説明は不要です」 |

### 実例

**質問**: Dockerのマルチステージビルドについて教えて。あなたはシニアエンジニアです。初心者向けの説明は不要です。

**回答**:
```dockerfile
FROM node:20 AS builder
WORKDIR /app
COPY package*.json ./
RUN npm ci
COPY . .
RUN npm run build

FROM node:20-slim
WORKDIR /app
COPY --from=builder /app/dist ./dist
COPY --from=builder /app/node_modules ./node_modules
CMD ["node", "dist/main.js"]
```

builderステージでビルドし、本番イメージにはビルド成果物だけコピーします。イメージサイズが1/3〜1/5になります。

ChatGPTの活用法をもっと知りたい方は[AI検索とGoogle検索の使い分け](/posts/ai-vs-google-search/)も参考になります。

## テクニック5：テンプレートを渡す

### 追加する行

```
以下のフォーマットで回答してください：
【結論】
【理由】
【具体例】
```

### なぜ効くのか

フォーマットを指定すると、ChatGPTはその枠に収まるように回答を構造化します。余計な情報が自然と削ぎ落とされます。

### 実例

**質問**: React vs Vue、個人開発ならどっちがいい？以下のフォーマットで回答してください：
【結論】
【理由】
【具体例】

**回答**:
【結論】個人開発ならVueのほうが始めやすい
【理由】学習コストが低く、単一ファイルコンポーネントで小さく始められるため
【具体例】ToDoアプリ程度なら、Vueは公式チュートリアル完了後すぐ作れる。Reactはstate管理の選択肢（useState / useReducer / Zustand等）で迷いやすい

構造化されているので、読む側も一瞬で要点を把握できます。

## 5つのテクニックの使い分けガイド

| やりたいこと | 使うテクニック | 追加する1行 |
|-------------|--------------|------------|
| 要点だけ知りたい | テクニック1 | 「箇条書き3つで」 |
| SNS用の短文がほしい | テクニック2 | 「100文字以内で」 |
| コードだけほしい | テクニック3 | 「前置きと注意書きは省略」 |
| 自分のレベルに合わせたい | テクニック4 | 「シニアエンジニアとして」 |
| 決まった形式で出したい | テクニック5 | テンプレートを渡す |

## 筆者が実際に試して分かったこと

### 良かった点

- テクニック1〜3は即効性が高い。今日から使える
- テクニック4は繰り返し質問するとき特に効果的
- テクニック5は仕事の報告書作成で重宝している

### イマイチだった点

- 「50文字以内」のような極端に短い制限は守られないことがある（70文字くらいになる）
- ロール設定は長い会話だと途中で忘れられることがある → 定期的にリマインドが必要
- 複雑な質問では、短くしすぎると重要な情報が抜けることもある

### 組み合わせのコツ

テクニックは組み合わせると最強です。筆者がよく使うテンプレート：

```
あなたはシニアエンジニアです。
以下の質問に箇条書き3つ以内で答えてください。
前置きは不要です。

質問: ○○○○
```

これで毎回的確な回答が返ってきます。

## よくある質問（FAQ）

### Q: 「短く答えて」と「100文字以内で」の違いは？

A: 「短く答えて」は曖昧なので、ChatGPTが「短い」をどう解釈するかブレます。「100文字以内」のように数字で指定すると、ほぼ正確に従ってくれます。具体的な数字を使いましょう。

### Q: 無料版でもこのテクニックは使えますか？

A: はい。プロンプトの書き方なので、無料版（GPT-4o mini）でも有料版（GPT-4o）でも同じように使えます。

### Q: これらのテクニックはChatGPT以外のAIでも使えますか？

A: ほぼ使えます。Gemini、Claude、Copilotなど主要なAIアシスタントは同様の指示に対応しています。ただし、AIによって従い方に若干の差があります。

### Q: カスタム指示（Custom Instructions）との違いは？

A: カスタム指示は「常に適用されるデフォルト設定」、プロンプト内の指示は「その質問だけに適用される一時設定」です。毎回同じ形式で回答してほしいなら、カスタム指示に設定するのが便利です。
